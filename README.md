# Мультик с Дедом Морозом

Сайт-лендинг: именное новогоднее поздравление от Деда Мороза.

- `index.html` — сайт; все настройки в блоке `CONFIG` внизу файла (цены, ссылки на оплату, адрес приёма заявок).
- `Code.gs` — код приёма заявок для Google Apps Script (в репозитории без токенов).
- `ЗАПУСК САЙТА.txt` — пошаговая инструкция.

Публикация: Settings → Pages → Deploy from a branch → `main` / `(root)`.
